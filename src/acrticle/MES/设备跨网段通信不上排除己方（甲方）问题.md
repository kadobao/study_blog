## 概述

在 MES 系统设备接入过程中，跨网段通信故障是常见问题之一。本文档从甲方角度出发，提供系统性的网络排查方法，用于排除己方设备、网络配置及线路方面的潜在问题，为后续与乙方协同定位故障奠定基础。

## 默认网关获取

将计算机通过网线接入网络插座，并将 IP 获取方式设置为 DHCP 自动获取。在命令提示符中执行 `ipconfig` 命令，查询结果中显示的网关地址即为交换机或路由器所配置的默认网关地址。

## 子网掩码与网段划分

子网掩码的配置直接决定跨网段通信时是否经由网关转发。子网掩码中对应位为 `255` 的部分表示网络地址，剩余部分为主机地址。网络地址相同的设备属于同一网段，通信时无需经过网关；网络地址不同的设备属于不同网段，通信时需经由网关转发。

以下为常见子网掩码的网段划分示例：

- **子网掩码 `255.255.255.0`**：前三位网络地址相同即为同网段。例如 `192.168.22.12` 与 `192.168.22.130` 属于同网段，而与 `192.168.21.120` 属于不同网段。
- **子网掩码 `255.255.0.0`**：前两位网络地址相同即为同网段。例如 `192.168.22.12` 与 `192.168.22.130` 属于同网段，同时与 `192.168.21.120` 也属于同网段。

## 跨网关通信验证

当满足以下条件时，跨网段通信将经由网关转发：

- 已正确配置默认网关；
- 子网掩码为 `255.255.255.0`；
- 本机 IP 为 `192.168.22.130`，目标设备 IP 为 `192.168.21.120`。

在上述配置下，执行 `ping 192.168.21.120` 时，数据包将经由默认网关进行路由转发。

## 线路与设备排查

以下步骤用于逐步排除物理线路及网络设备的潜在故障：

1. **线路验证**：将计算机通过网线接入网络插座，并禁用 WLAN 无线连接。若能够 `ping` 通同网段内的其他 IP 地址，则说明网线物理连接正常。
2. **IP 与网络设备验证**：将计算机 IP 设置为目标设备所使用的 IP 地址，从另一台计算机对该 IP 执行 `ping` 命令。若能够 `ping` 通，则说明该 IP 地址可用，且路由器或交换机工作正常。
