## 前言

本文记录在 Windows 电脑上安装 IDPRT（汉印）标签打印机驱动的完整过程，
包括连接打印机、安装驱动、测试打印三部分。

## 一、连接打印机到电脑

使用 USB 打印连接线连接打印机和电脑。
连接线的打印机端为梯形方口，插到打印机背面的 USB 接口上：

![USB打印连接线样式_1](/assets/images/USB打印连接线样式_1.jpg)

![USB打印连接线样式_2](/assets/images/USB打印连接线样式_2.jpg)

另一端为标准 USB 接口，插到电脑的 USB 接口：

![打印机连接电脑_1](/assets/images/打印机连接电脑_1.jpg)

![打印机连接电脑_2](/assets/images/打印机连接电脑_2.jpg)

## 二、下载并安装驱动

从 IDPRT 官网下载对应型号的驱动安装包，双击运行：

![安装软件](/assets/images/安装软件.png)

### 1. 选择连接方式

打开驱动安装向导，选择 USB 连接方式，
按提示将打印机关机再开机，向导会自动搜索检测打印机：

![打印机连接线安装驱动_1](/assets/images/打印机连接线安装驱动_1.png)

### 2. 确认检测到的打印机

向导检测到 IDPRT 打印机型号后，点击「下一页」继续：

![打印机连接线安装驱动_2](/assets/images/打印机连接线安装驱动_2.png)

### 3. 设置打印机名称

保持默认名称或自定义打印机名称，点击「下一页」开始安装：

![打印机连接线安装驱动_3](/assets/images/打印机连接线安装驱动_3.png)

## 三、搜索不到打印机时：选择其他连接方式安装

> 如果 USB 安装时一直搜索不到打印机（关机再开机也不行），
> 可以在「连接打印机」这一步选择「其他(如并行或串行)」手动安装：

![选择其他连接](/assets/images/选择其他连接.png)

点击「下一页」后，在「指定打印机型号」页面根据打印机底部标签确认型号
（本例为 iDPRT ST34S (300 dpi)）：

![根据打印机底部标签选择打印机型号](/assets/images/根据打印机底部标签选择打印机型号.png)

然后在「指定端口」页面选择打印机的 USB 虚拟打印端口
（如 USB004 - iDPRTST34S3），点击「下一页」继续安装：

![选择端口](/assets/images/选择端口.png)

## 四、通过网络连接安装驱动（局域网）

如果打印机需要多台电脑共用，可以用网线将打印机接入局域网，通过网络方式安装驱动。

### 1. 用 USB 连接确认打印机可用

先用 USB 连接电脑，打开「标签打印机设置工具」，在「功能测试」页点击「打印自检页」，
测试工具软件是否连接上了标签打印机：

![测试是否连接了标签打印机](/assets/images/网络连接_测试是否连接了标签打印机_1.png)

### 2. 为打印机设置固定 IP

在「参数设置」页，通讯接口选择 USB，切换到「以太网」选项卡，为打印机设置固定的 IP 地址
（IP 要设置为没有人使用的地址，不然会冲突），设置完成后点击「当前设置」：

![为标签打印机设置IP](/assets/images/网络连接_为标签打印机设置IP_2.png)

### 3. 驱动向导选择网络连接

再次打开驱动安装向导，连接方式选择「网络(以太网或无线网络)」：

![选择网络连接](/assets/images/网络连接_选择网络连接_3.png)

### 4. 选择打印机型号

在「指定打印机型号」页面选择 `iDPRT ST34S (300 dpi)`：

![选择打印机型号](/assets/images/网络连接_选择打印机型号_4.png)

### 5. 创建 TCP/IP 端口

在「指定端口」页面点击「创建端口(C)...」：

![创建端口](/assets/images/网络连接_创建端口_5.png)

端口类型选择「Standard TCP/IP Port」，点击「新建端口(N)...」：

![选择创建端口类型](/assets/images/网络连接_选择创建端口类型_6.png)

在弹出的「添加标准 TCP/IP 打印机端口向导」中，
「打印机名或 IP 地址」填入之前设置好的 IP 地址（本例为 10.1.190.156），端口名会自动填充：

![输入之前设置好的IP地址](/assets/images/网络连接_输入之前设置好的IP地址_7.png)

### 6. 选择创建好的端口

回到「指定端口」页面，选择刚刚创建好的端口
（10.1.190.156 - 标准 TCP/IP 端口）：

![选择创建好的端口](/assets/images/网络连接_选择创建好的端口_8.png)

### 7. 完成端口创建

如果提示「不能识别设备」，设备类型保持默认的「标准 - Generic Network Card」，
直接点击「下一页」就行：

![点击下一页](/assets/images/网络连接_点击下一页_9.png)

### 8. 命名打印机

保持默认名称或者自定义命名（如「MES开发测试使用的箱贴标签打印机」），
点击「下一页」完成安装：

![默认或者自定义命名](/assets/images/网络连接_默认或者自定义命名_10.png)

## 五、测试是否安装成功

安装完成后，打开 Windows「设置 → 蓝牙和其他设备 → 打印机和扫描仪」，
找到刚安装的 IDPRT 打印机，点击「打印机属性 → 打印测试页」验证驱动是否安装成功：

![测试是否安装成功](/assets/images/测试是否安装成功.png)
